# @agenvo/codex-app-server

[简体中文](README.zh-CN.md)

Attach to an existing Codex app-server or manage an isolated process.

```sh
npm install --global @agenvo/codex-app-server@0.1.0
```

For AI agents: follow the [installation guide](https://github.com/Xuanwo/agenvo/blob/v0.1.0/docs/installation.md) for relay deployment, device pairing, and client authorization.

Requires Node.js 24.13+. Installing a Connector does not install Herdr or Codex.

[Usage and deployment](https://github.com/Xuanwo/agenvo/blob/v0.1.0/docs/usage.md)
