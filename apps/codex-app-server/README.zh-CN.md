# @agenvo/codex-app-server

[English](README.md)

通过 Unix socket 或 loopback WebSocket 连接独立运行的 Codex app-server。关闭或更新 Connector 不会停止原生服务及其轮次。

<!-- x-release-please-start-version -->

```sh
npm install --global @agenvo/codex-app-server@0.2.0-rc.1
```

<!-- x-release-please-end -->

AI Agent 请按照[安装指南](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.1/docs/installation.zh-CN.md)完成中继部署、设备配对和客户端授权。 <!-- x-release-please-version -->

需要 Node.js 24.13+。安装 Connector 不会安装 Herdr 或 Codex。
