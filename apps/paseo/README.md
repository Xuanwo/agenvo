# @agenvo/paseo

[简体中文](README.zh-CN.md)

Attach to an independently running Paseo daemon and manage its native agents. Closing the Connector leaves the daemon and native execution running.

```sh
npm install --global @agenvo/paseo@0.2.0-rc.1
```

For AI agents: use the [installation guide](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.1/docs/installation.md).

Requires Node.js 24.13+. The Connector does not install Paseo or its providers.

[Configuration, pairing and usage](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.1/docs/usage.md)
