# @agenvo/paseo

[English](README.md)

附着独立运行的 Paseo daemon，管理其原生 Agent。关闭 Connector 不会停止 daemon 或原生执行。

<!-- x-release-please-start-version -->

```sh
npm install --global @agenvo/paseo@0.2.1
```

<!-- x-release-please-end -->
