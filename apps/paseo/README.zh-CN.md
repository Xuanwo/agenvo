# @agenvo/paseo

[English](README.md)

附着独立运行的 Paseo daemon，管理其原生 Agent。关闭 Connector 不会停止 daemon 或原生执行。

```sh
npm install --global @agenvo/paseo@0.1.0
```

面向 AI Agent：使用[安装指南](https://github.com/Xuanwo/agenvo/blob/v0.1.0/docs/installation.zh-CN.md)。Agenvo 尚未正式发布。

要求 Node.js 24.13+。Connector 不安装 Paseo 或 provider。

[配置、配对与使用](https://github.com/Xuanwo/agenvo/blob/v0.1.0/docs/usage.zh-CN.md)
