# @agenvo/lody

[English](README.md)

通过 Lody 原生文档同步与 RPC 连接云端 workspace 或附着已有本机 daemon。云端和本地实例可以共存，关闭 Connector 后原生工作继续运行。

<!-- x-release-please-start-version -->

```sh
npm install --global @agenvo/lody@0.2.0-rc.1
```

<!-- x-release-please-end -->

需要 Node.js 24.13+。

云端连接需要 CLI token 与 workspace 访问权；本地附着需要同机已启动的 daemon。请使用[安装指南](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.1/docs/installation.zh-CN.md)。 <!-- x-release-please-version -->
