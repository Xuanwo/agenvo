# @agenvo/lody

[English](README.md)

通过 Lody 原生文档同步与 RPC 连接云端 workspace 或附着已有本机 daemon。云端和本地实例可以共存，关闭 Connector 后原生工作继续运行。

需要 Node.js 24.13+。云端连接需要 CLI token 与 workspace 访问权；本地附着需要同机已启动的 daemon。Agenvo 尚未正式发布，请使用[源码安装指南](https://github.com/Xuanwo/agenvo/blob/main/docs/installation.zh-CN.md)。

[配置与使用](https://github.com/Xuanwo/agenvo/blob/main/docs/lody.zh-CN.md)
