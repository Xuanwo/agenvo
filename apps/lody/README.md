# @agenvo/lody

[简体中文](README.zh-CN.md)

Manage a Lody cloud workspace or attach to an existing local daemon through native document synchronization and RPC. Cloud and local instances can coexist. Closing the Connector leaves native work running.

```sh
npm install --global @agenvo/lody@0.2.0-rc.0
```

Requires Node.js 24.13+. Cloud access needs a CLI token and workspace access; local attachment needs a running daemon on the same machine. Follow the [installation guide](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.0/docs/installation.md).

[Configuration and usage](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.0/docs/lody.md)
