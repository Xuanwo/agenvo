# @agenvo/dsh

[简体中文](README.zh-CN.md)

Attach to a running DeepSeek Harness (DSH) desktop app through the native bridge of the dsh-grokbot-dispatch plugin. Discover every desktop session, including sessions opened by hand, create sessions, submit input, read output, interrupt turns and answer agent questions. Closing the Connector leaves DSH running.

Requires Node.js 24.13+. This new Connector is available from source; no npm release is published yet.

[Install the bridge, configure and use DSH](https://github.com/Xuanwo/agenvo/blob/main/docs/dsh.md)
