# @agenvo/dsh

[English](README.md)

通过 dsh-grokbot-dispatch 插件的原生桥接连接正在运行的 DeepSeek Harness（DSH）桌面版。发现全部桌面会话（包括手动打开的会话）、创建会话、提交输入、读取输出、中断轮次和回答 Agent 的提问。关闭 Connector 不会停止 DSH。

需要 Node.js 24.13+。此新增 Connector 目前从源码构建，尚未发布 npm 版本。

[安装桥接、配置与使用 DSH](https://github.com/Xuanwo/agenvo/blob/main/docs/dsh.zh-CN.md)
