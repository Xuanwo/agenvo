# @agenvo/herdr

[English](README.md)

连接独立运行的 Herdr。

```sh
npm install --global @agenvo/herdr@0.2.0-rc.0
```

AI Agent 请按照[安装指南](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.0/docs/installation.zh-CN.md)完成中继部署、设备配对和客户端授权。

需要 Node.js 24.13+。安装 Connector 不会安装 Herdr 或 Codex。

[使用与部署说明](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.0/docs/usage.zh-CN.md)
