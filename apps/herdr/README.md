# @agenvo/herdr

[简体中文](README.zh-CN.md)

Connect independently running Herdr services.

```sh
npm install --global @agenvo/herdr@0.2.0-rc.1
```

For AI agents: follow the [installation guide](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.1/docs/installation.md) for relay deployment, device pairing, and client authorization.

Requires Node.js 24.13+. Installing a Connector does not install Herdr or Codex.

[Usage and deployment](https://github.com/Xuanwo/agenvo/blob/v0.2.0-rc.1/docs/usage.md)
