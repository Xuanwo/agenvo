# @agenvo/opencode

[简体中文](README.zh-CN.md)

Attach to an independently running OpenCode HTTP server. Discover existing native sessions across projects, submit input, read output and interrupt execution. Closing the Connector leaves the server running.

Requires Node.js 24.13+. This new Connector is available from source; no npm release is published yet.

[Build, configure and use OpenCode](https://github.com/Xuanwo/agenvo/blob/main/docs/opencode.md)
