# @agenvo/server

[English](README.md)

在 VPS 上运行 Agenvo Relay。

```sh
npm install --global @agenvo/server@0.1.0
```

AI Agent 请按照[安装指南](https://github.com/Xuanwo/agenvo/blob/v0.1.0/docs/installation.zh-CN.md)完成中继部署、设备配对和客户端授权。

需要 Node.js 24.13+。Agent 运行时位于另行配对的 Connector 上。

[使用与部署说明](https://github.com/Xuanwo/agenvo/blob/v0.1.0/docs/deployment-vps.zh-CN.md)
