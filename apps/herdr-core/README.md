# @agenvo/herdr-core

[简体中文](README.zh-CN.md)

Attach an independently running herdr-core (`hc`) core and manage its terminals and agents. Stopping the connector does not stop the core or its programs.

<!-- x-release-please-start-version -->

```sh
npm install --global @agenvo/herdr-core@0.2.0
```

<!-- x-release-please-end -->

For AI agents: use the [installation guide](https://github.com/Xuanwo/agenvo/blob/v0.2.0/docs/installation.md). <!-- x-release-please-version -->

Requires Node.js 24.13+. The connector does not install or start herdr-core.

[Configuration, pairing and usage](https://github.com/Xuanwo/agenvo/blob/v0.2.0/docs/usage.md) <!-- x-release-please-version -->
