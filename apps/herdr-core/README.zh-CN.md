# @agenvo/herdr-core

[English](README.md)

附着独立运行的 herdr-core（`hc`）core，管理其中的 terminal 和 Agent。关闭 Connector 不会停止 core 或其中的程序。

<!-- x-release-please-start-version -->

```sh
npm install --global @agenvo/herdr-core@0.2.0
```

<!-- x-release-please-end -->

面向 AI Agent：使用[安装指南](https://github.com/Xuanwo/agenvo/blob/v0.2.0/docs/installation.zh-CN.md)。 <!-- x-release-please-version -->

要求 Node.js 24.13+。Connector 不安装或启动 herdr-core。
